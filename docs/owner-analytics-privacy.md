# لوحة مالك Rebel AI: المقاييس وحدود الخصوصية

## الهدف

تمكّن اللوحة حساب **Rebel Ai** فقط من تقييم استقرار النسخة التجريبية واستهلاك الحصة المجانية قبل اتخاذ أي قرار تجاري. لا تُعد أداة لقراءة محادثات الناس أو مراقبتهم.

## ما يُسجَّل

| المقياس | الغرض | لا يتضمن |
|---|---|---|
| وقت حدوث طلب الذكاء الاصطناعي | قياس النشاط اليومي والساعة النشطة | نص الرسالة أو عنوان المحادثة |
| الحساب الداخلي | حساب المستخدمين النشطين المجمّعين | الاسم الظاهر أو البريد في اللوحة |
| النموذج والموفّر الفعليان | قياس التوزيع والتحويل التلقائي | مفتاح API |
| حالة النتيجة | رصد النجاح، الحد اليومي، الحد الزمني، وحدّ الموفّر | تفاصيل المحادثة |
| زمن الاستجابة بالميلي ثانية | قياس البطء والاستقرار | محتوى الرد |
| وقوع التحويل التلقائي | معرفة ضغط الموفّرين | أي بيانات شخصية |

## ما لا يُسجَّل في التحليلات

لا تسجل طبقة التحليلات نصوص رسائل المستخدم أو ردود الذكاء الاصطناعي أو عناصر الذاكرة أو البريد أو كلمة المرور أو قيمة مفتاح API أو IV أو وسم التشفير أو عنوان IP.

## ما سيعرض للمالك

تعرض اللوحة أرقاماً مجمعة فقط: الحسابات النشطة، الرسائل خلال اليوم أو آخر سبعة أيام، النتائج الناجحة والأخطاء، الحدود اليومية والزمنية، توزيع النماذج، عدد التحويلات، ومتوسط زمن الاستجابة. لا توجد قائمة مستخدمين أو شاشة لتصفح محتوى أي محادثة.
