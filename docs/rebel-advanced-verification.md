# تحقق دفعة Rebel AI المتقدمة

## ما تم تنفيذه

تضيف هذه الدفعة قياسات تشغيل مجمعة، فحصاً يدوياً لحالة المزوّدين لحساب المالك، دفتر أدلة قابل للتحرير داخل المشروع، ومخرجات مشروع قابلة للتحرير والنسخ والمشاركة. كما توثق الحوكمة المطلوبة قبل أي ملفات خارجية أو مصادر ويب أو تكاملات أو Live صوتي مستمر.

| المسار | حالة التحقق |
|---|---|
| TypeScript | ناجح |
| قواعد Expo | ناجح، مع تحذير بيئة Node المعروف فقط |
| اختبارات الوحدة | 25 ناجحاً؛ 4 اختبارات حيّة متخطاة عمداً لأنها تعتمد على موفّرات خارجية |
| حسابات وسحابة وعزل وحذف | ناجح عبر smoke شامل يشمل الدليل والمخرجات والتصدير |
| قاعدة البيانات | migrations 0006 و0007 و0008 مطبقة بنجاح، وكلها إضافية غير هدمية |

## ما يحتاج اختبار هاتف فعلي

لا تثبت هذه النتائج قائمة أصوات Android الفعلية، إذن الميكروفون، Rebal Live، المشاركة عبر تطبيقات الهاتف، أو سلوك الشبكة الضعيفة. توجد قائمة اختبار ميداني في `docs/android-field-test-checklist.md` ويجب تنفيذها على APK حديث قبل إعلان جاهزية عامة.

## حدود مقصودة

لا يتصل Rebel حالياً بمصادر ويب أو ملفات مستخدمين أو OAuth خارجي، ولا يدّعي Rebal Live كاتصال صوتي مستمر. كذلك لا يصف Groq بأنه متاح قبل نجاح الفحص اليدوي؛ عند 403 أو التعذر يتحول المسار إلى البديل المجاني بدلاً من قطع المحادثة.
