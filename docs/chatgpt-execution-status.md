# حالة تنفيذ توجيه ChatGPT في Rebel AI

**تاريخ التحديث:** 23 أغسطس 2026  
**القاعدة التشغيلية:** لم يُفعَّل اشتراك أو Billing أو نموذج مدفوع أو خدمة خارجية أو نشر خلال هذه الدفعة.

## ما نُفذ فعلياً

| المجال | التنفيذ الفعلي | الضمان التشغيلي |
|---|---|---|
| المشاريع | جداول ومهام API وشاشة `Rebel Projects` لإنشاء المشروع وتعديله واختياره وحذفه | كل مشروع مرتبط بـ `accountId`؛ حذف المشروع يفك الارتباط فقط ولا يحذف المحادثات أو الذكريات |
| الذاكرة | مفتاح تشغيل/إيقاف، تعديل عنصر الذاكرة، حذف، فئات، وربط اختياري بالمشروع النشط | عند الإيقاف لا تُسترجع الذاكرة في الطلبات الجديدة؛ لا يوجد حفظ تلقائي للذاكرة |
| المحادثة المؤقتة | وضع محادثة من الواجهة ومسار الخادم | لا ينشئ سجلاً سحابياً أو ذاكرة، ولا يضيف الرسائل إلى التخزين المحلي الدائم |
| سياق المشروع | تمرير تعليمات المشروع المملوكة للحساب فقط إلى المحادثة | تتحقق الخوادم من ملكية المشروع قبل استخدامه أو ربط ذاكرة به |
| Rebal Live | تحسين Push-to-Talk بحيث يمكن مقاطعة النطق بجولة جديدة، ويطبق وضع المحادثة المؤقتة | ليس بثاً حيّاً كاملاً، ولا يُسوّق على أنه كذلك |
| التصدير | زر لتجهيز ملف JSON محلي ومشاركته من Android أو iOS | يتضمن المحتوى الذي يملكه الحساب؛ يستثني كلمة المرور وقيم مفاتيح API والرموز والجلسات والتحليلات |
| الإضافات | إزالة زر الربط الوهمي وإظهار حقيقة عدم وجود تكامل نشط | لا تُمنح أي صلاحية ولا يُقرأ أي حساب خارجي حالياً |
| الاختبارات | توسعة الاختبار التشغيلي للحسابات | غطى المشروع والذاكرة وإعدادات الذاكرة والتصدير والعزل والحذف الشامل |

## ما هو قائم من الأساس وما بقي محمياً

يبقى التسلسل المجاني للنماذج **Gemini Flash ثم Qwen عبر Groq ثم Mistral Small** كما هو، مع الحصة اليومية والحد الزمني والتحويل الهادئ. لا يوجد بديل مدفوع تلقائي. كما بقيت بيانات الحسابات والمحادثات والذكريات ومفاتيح المستخدمين معزولة بحسب الحساب، ومفاتيح API الشخصية مشفرة ولا تدخل في ملف التصدير.

## بنود لم تُفعل في هذه الدفعة

| البند | سبب عدم التفعيل الآن |
|---|---|
| Billing وPlus وPro والدفع داخل المتجر | يحتاج قراراً مالياً مكتوباً، أسعاراً، سياسات استرداد، ومراقبة استهلاك قبل تشغيله |
| نموذج مدفوع احتياطي | يتطلب موافقة مالية صريحة ومفتاحاً أو رصيداً رسمياً |
| Rebal Live ثنائي الاتجاه أو البث المستمر | يحتاج مزود بث صوتي، اختبار شبكة، ونموذج تكلفة بالدقيقة |
| رفع الملفات وتحليل الصور والويب المباشر | يحتاج حدود محتوى وتخزين ومراجعة خصوصية وخدمة تكامل محددة قبل تفعيله |
| ربط Google Drive وGitHub وNotion وSlack وCalendar | يحتاج OAuth وموافقة تحدد النطاقات وفترة الاحتفاظ وإلغاء التفويض |
| استعادة كلمة المرور والتحقق بالبريد | يحتاج خدمة بريد ومعالجة عملياتية مستقلة |
| اختبار الصوت Android على جهاز فعلي | يتطلب تجربة منك على هاتف حقيقي؛ لا يمكن إثبات سلوك الميكروفون والمقاطعات من محاكي الويب |

## نتيجة التحقق لهذه الدفعة

نجح فحص TypeScript، وفحص القواعد، واختبارات Vitest، واختبار الحسابات التشغيلي الذي أنشأ حساباً ومشروعاً وذاكرة وإعدادات ذاكرة وملف تصدير، ثم اختبر العزل والحذف الكامل ونظف بيانات الاختبار.
