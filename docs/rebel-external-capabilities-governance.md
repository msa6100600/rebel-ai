# حوكمة ملفات المشروع والمصادر وRebal Live والتكاملات

## مبدأ الموافقة أولاً

لا يرفع Rebel AI ملفاً أو يقرأ مصدر ويب أو يربط حساباً خارجياً أو ينفذ إجراءً خارج التطبيق من تلقاء نفسه. قبل كل عملية، يعرض للمستخدم نوع البيانات، الغرض، مكان الاستخدام، والنتيجة المتوقعة، مع خيار الإلغاء.

| القدرة | موافقة مطلوبة | البيانات المسموح بها | ما لا يحدث تلقائياً |
|---|---|---|---|
| ملف مشروع | اختيار المستخدم للملف وتأكيد الإضافة | اسم الملف، النوع، الحجم، والنص المستخرج عند الطلب | لا يرفع الملف عند فتح المشروع |
| مصدر ويب | إدخال الرابط وتأكيد القراءة | رابط المصدر، وقت القراءة، والمقتطفات المستخدمة | لا يتصفح Rebel الويب في الخلفية |
| تكامل خارجي | شاشة صلاحيات صريحة لكل خدمة | الصلاحية المحددة ومدة الربط | لا يرسل رسائل أو ينشئ ملفات أو يعدّل حسابات |
| Rebal Live | إذن ميكروفون لكل نظام وتشغيل واضح | الصوت أثناء الجلسة فقط | لا يسجل دائماً أو يعمل في الخلفية بلا إشعار |

## ملفات المشروع

يبدأ التنفيذ بدفعة صغيرة: نصوص وملفات PDF أو DOCX يختارها المستخدم، مع حد حجم معلن، حالة رفع ظاهرة، زر حذف، وبيان الاحتفاظ. تسجل قاعدة البيانات الوصف فقط؛ تحفظ البايتات في التخزين المخصص؛ ويتوقف ظهور الملف عند حذف مرجعه من المشروع. قبل الإطلاق يحدد المالك حد الحجم، المدة القصوى للاحتفاظ، وهل يمكن تحليل الصور أم لا.

## دفتر المصادر

كل مصدر داخل المشروع يحمل الرابط أو اسم الملف، تاريخ الإضافة، حالة القراءة، ومقتطفاً استخدمه Rebel في الاستنتاج. تظهر بطاقة الدليل الفرق بين «نص من المصدر» و«استنتاج Rebel» و«افتراض غير متحقق». لا تُمنح درجة ثقة مرتفعة لمعلومة لا تملك مصدراً أو دليلاً داخل المشروع.

## Rebal Live

يبقى Rebal Live حالياً Push-to-Talk. التحول إلى Live حقيقي لا يبدأ إلا بعد نجاح قائمة اختبار Android وتحديد مزود وسعة وتكلفة. يحتاج Live: جلسة اتصال مستمرة، تدفق صوت ثنائي الاتجاه، إيقاف نطق الرد عند حديث المستخدم، إعادة اتصال آمنة، ومؤشرات صريحة لحالة الميكروفون. لا يصح تسميته Live قبل تحقق هذه الشروط ميدانياً.

## التكاملات

تبدأ أي تكاملات مستقبلية في وضع «قراءة فقط» وبسجل موافقات. لكل ربط: اسم الخدمة، نطاق الصلاحية، سبب الطلب، زر فصل، ومؤشر آخر استخدام. تتطلب الأفعال التي تغير بيانات خارج التطبيق تأكيداً منفصلاً في لحظة التنفيذ.
