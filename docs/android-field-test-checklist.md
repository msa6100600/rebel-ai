# قائمة اختبار Rebel AI على Android

هذه القائمة مخصّصة للهاتف الفعلي بعد تثبيت APK حديث. لا يمكن لمعاينة الويب أو اختبارات الخادم تأكيد نتيجة هذه البنود.

| المسار | الإجراء | النتيجة المتوقعة | النتيجة الفعلية |
|---|---|---|---|
| الدخول | أغلق التطبيق وافتحه ثم سجّل الدخول | تُنشأ الجلسة وتبقى بعد إعادة الفتح | ☐ |
| المحادثة | أرسل سؤالاً فصحى ثم مصرياً ثم إنجليزياً | يظهر رد باللغة/اللهجة المختارة مع بطاقة دليل وسياق | ☐ |
| النماذج | جرّب النموذج الافتراضي ثم بدّل النموذج | يظهر اسم النموذج الذي أنهى الرد أو رسالة تعذر واضحة | ☐ |
| المشروع والذاكرة | اختر مشروعاً وأنشئ ذاكرة ثم أرسل سؤالاً مرتبطاً | تعرض البطاقة المشروع أو الذاكرة المستخدمة من دون محتوى حساب آخر | ☐ |
| محادثة مؤقتة | فعّل المحادثة المؤقتة ثم أرسل سؤالاً | لا تستخدم ذاكرة محفوظة ولا يظهر السجل بعد المغادرة | ☐ |
| قائمة الأصوات | افتح الإعدادات واختر صوتاً متاحاً فعلياً | لا تظهر أسماء رمزية غير متاحة، ويُستخدم الصوت المختار عند النطق | ☐ |
| Rebal Live | امنح إذن الميكروفون، سجّل جولة قصيرة ثم أوقفها | يظهر تفريغ أو خطأ مرحلة واضح؛ يمكن بدء جولة جديدة لإيقاف النطق السابق | ☐ |
| الخلفية والمقاطعة | أثناء التسجيل بدّل التطبيق ثم عُد، وجرّب أثناء مكالمة هاتفية إن أمكن | لا يتعطل التطبيق؛ تظهر رسالة قابلة للفهم عند انقطاع التسجيل | ☐ |
| المشاركة والنسخ | انسخ رداً وشاركه إلى تطبيق آخر | يصل النص المختار ولا تتضمن المشاركة مفاتيح أو جلسات | ☐ |
| شبكة ضعيفة | شغّل وضع طيران ثم أعد الاتصال أثناء انتظار رد | رسالة عربية واضحة وزر إعادة محاولة؛ لا تتجمد الواجهة | ☐ |
| الحساب والخصوصية | صدّر البيانات ثم سجّل خروجاً | التصدير يستثني كلمات المرور والمفاتيح والجلسات؛ يعود التطبيق للدخول | ☐ |

## ما يجب إرساله عند ظهور عطل

أرسل **لقطة شاشة ورسالة الخطأ فقط**، مع نوع الهاتف وإصدار Android وخطوات تكرار العطل. لا ترسل كلمة مرور أو مفتاح API أو محتوى خاص غير لازم للتشخيص.
