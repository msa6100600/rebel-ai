### (C) Concrete Features and Constraints
*   **Persistent Project Memory:** Unlike standard chats where memory is global and potentially vague, Projects maintain a "single brain" specific to that folder.
*   **Memory Settings:** Users can choose between **"Default"** (accesses memories from outside chats) and **"Project-only"** (strictly limited to the internal project context).
*   **File Integration:** Supports uploading documents (PDFs are shown in the demo) that the AI references as a knowledge base.
*   **Custom Instructions:** A dedicated text area to define the AI's role, specific tasks (e.g., "Keep me aligned with the correct onboarding sequence"), and response style.
*   **Chat Management:** Features include renaming projects/chats, moving chats between different projects, and archiving or deleting chats.
*   **Collaboration:** Projects can be shared with others via email, though they are not public-facing like the GPT Store.
*   **UI Constraint:** The **ChatGPT Desktop App** currently lacks the ability to rename chats within a project, a feature available only on the web and mobile versions.

2.  **Memory Configuration:** Select the memory scope (Default vs. Project-only).
